# PROJECTS

One folder per venture or bet. Each holds a `project.md` — the living front
door for any AI tool that touches that project.

| Slug | Name | Status |
|---|---|---|
| `taylors-tech` | Taylor's Tech | building |
| `taylor-dynasty` | Taylor Dynasty | building |
| `oasis-marketplace` | Oasis Marketplace | building |
| `ai-agent-harness` | AI Agent Harness | building |
| `tayvora` | Tayvora | idea |

A project folder is **never** just a folder — it always carries a `project.md`
in the template format (`../templates/project.md`). Work for a project happens
*inside* its folder; shared knowledge goes to `../KNOWLEDGE/`; shared raw
material goes to `../ASSETS/`.
