# Prompts

Reusable, versioned prompts for the AI tools. Each is a spec-like file in the
`../../templates/prompt.md` format, so prompts get the same discipline as code:
versioned, reviewed, and improved instead of copy-pasted into a chat and lost.

Use the `model:` field to note which tool a prompt is tuned for
(`chatgpt`, `claude`, `gemini`, or `any`).

| Prompt | Purpose |
|---|---|
| `on-brand-copy.md` | Generate on-brand copy under the house voice + rules |
